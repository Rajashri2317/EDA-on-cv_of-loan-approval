📊 Exploratory Data Analysis on Loan Approval Dataset
📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a Loan Approval dataset to understand the factors that influence loan approval decisions.

The main objective is to explore the dataset, identify patterns, analyze relationships between different variables, and gain meaningful insights into loan approval trends using Python and data visualization techniques.

🎯 Objectives
Understand the structure and characteristics of the loan approval dataset.
Perform data cleaning and preprocessing.
Identify and handle missing values.
Analyze numerical and categorical variables.
Explore relationships between applicant details and loan approval status.
Create meaningful visualizations to identify trends and patterns.
Extract useful insights from the dataset.

📁 Dataset Description

The project uses the loan_approved.csv dataset.

The dataset contains information related to loan applicants and their loan approval status.

It is used to explore applicant characteristics and understand patterns associated with loan approval and rejection.
